# Robocon

Robocon 机器人竞赛项目仓库。

本仓库将以下 3 个 GitHub 仓库合并为**独立分支**（互不合并到 main，各自保留完整提交历史）：

| 分支 | 来源仓库 |
|------|---------|
| `8.18practice` | [8.18practice](https://github.com/3280705778-cmd/8.18practice) |
| `demo` | [demo](https://github.com/3280705778-cmd/demo) |
| `git-practice-2026` | [git-practice-2026](https://github.com/3280705778-cmd/git-practice-2026) |

## 分支说明

- `main`：本说明文档，不包含具体代码
- 每个来源仓库对应一个独立分支，代码互不影响

## 使用方式

```bash
# 查看 8.18practice 的代码
git checkout 8.18practice

# 查看 demo 的代码
git checkout demo

# 查看 git-practice-2026 的代码
git checkout git-practice-2026
```
